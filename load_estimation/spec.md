# 短期电力负荷预测系统 - 规格说明书

## 1. 项目概述

### 1.1 项目背景

本项目旨在开发一个短期电力负荷预测系统，用于预测未来几分钟到几小时内的电力负荷需求。系统基于历史分钟级电力负荷数据，采用机器学习和深度学习方法构建预测模型。

### 1.2 数据来源与特点

| 属性 | 描述 |
|------|------|
| 数据格式 | Excel文件 (.xlsx/.xls) |
| 数据列 | 两列：时刻(Timestamp)、电力负荷值(Load) |
| 采样频率 | 分钟级采样 |
| 数据规模 | 约3年历史数据 (约1,576,800条记录) |
| 典型负荷范围 | 0 - 10000 MW (可根据实际数据调整) |

### 1.3 功能目标

1. 实现数据自动加载与预处理
2. 实现完整的数据合理性校验
3. 构建高效的特征工程 pipeline
4. 实现多种预测模型(XGBoost、LSTM)
5. 提供灵活的预测接口

## 3. 数据合理性校验方案

### 3.1 校验项目

| 校验类型 | 校验内容 | 处理方式 |
|----------|----------|----------|
| 完整性校验 | 检查缺失值、重复记录 | 标记并可选填充 |
| 范围校验 | 负荷值是否为正值、是否在合理范围 | 标记异常点 |
| 时间连续性 | 检查时间间隔是否一致 | 识别断点 |
| 异常值检测 | 使用IQR和Z-Score方法 | 标记供人工确认 |
| 单调性检查 | 检测负荷突变 | 计算相邻差分 |

### 3.2 校验流程

```
开始
  │
  ▼

  │
  ▼

  │
  ▼
检查完整性
  │
  ▼
检查时间连续性
  │
  ▼
检查数值范围
  │
  ▼
异常值检测
  │
  ▼
生成校验报告
  │
  ▼

```

## 4. 算法设计方案

### 4.1 特征工程设计

#### 4.1.1 时间特征

| 特征名称 | 描述 | 取值范围 |
|----------|------|----------|
| hour | 小时 | 0-23 |
| day_of_week | 星期几 | 0-6 |
| day_of_month | 日期 | 1-31 |
| month | 月份 | 1-12 |
| is_weekend | 是否周末 | 0/1 |
| is_holiday | 是否节假日 | 0/1 |
| minute_of_day | 一天中的分钟数 | 0-1439 |

#### 4.1.2 滞后特征 (Lag Features)

| 特征名称 | 描述 |
|----------|------|
| lag_1 | 前1分钟负荷 |
| lag_5 | 前5分钟负荷 |
| lag_15 | 前15分钟负荷 |
| lag_30 | 前30分钟负荷 |
| lag_60 | 前60分钟负荷 |
| lag_1440 | 前1天相同时间负荷 |

#### 4.1.3 滚动统计特征

| 特征名称 | 描述 |
|----------|------|
| rolling_mean_15 | 15分钟滚动平均 |
| rolling_std_15 | 15分钟滚动标准差 |
| rolling_mean_60 | 60分钟滚动平均 |
| rolling_std_60 | 60分钟滚动标准差 |
| rolling_mean_1440 | 1440分钟(1天)滚动平均 |

### 4.2 模型设计

#### 4.2.1 XGBoost 模型

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| n_estimators | 500 | 树的数量 |
| max_depth | 6 | 树的最大深度 |
| learning_rate | 0.05 | 学习率 |
| subsample | 0.8 | 行采样比例 |
| colsample_bytree | 0.8 | 列采样比例 |
| min_child_weight | 3 | 最小叶子节点样本权重 |
| reg_alpha | 0.1 | L1正则化 |
| reg_lambda | 1.0 | L2正则化 |

#### 4.2.2 LSTM 模型

| 参数 | 值 | 说明 |
|------|-----|------|
| input_dim | 特征数量 | 输入维度 |
| hidden_units | 64 | 隐藏层单元数 |
| num_layers | 2 | LSTM层数 |
| dropout | 0.2 | Dropout比例 |
| sequence_length | 60 | 序列长度 |
| dense_units | 32 | 全连接层单元数 |
| output_dim | 1 | 输出维度 |

#### 4.2.3 模型选择策略

1. **数据量 < 10万条**: 优先使用XGBoost
2. **数据量 >= 10万条**: 可考虑LSTM
3. **实时性要求高**: XGBoost (推理速度快)
4. **精度要求高**: 集成方法 (XGBoost + LSTM加权平均)

### 4.3 评估指标

| 指标 | 公式 | 说明 |
|------|------|------|
| MAE | mean(\|y - ŷ\|) | 平均绝对误差 |
| RMSE | sqrt(mean((y - ŷ)²)) | 均方根误差 |
| MAPE | mean(\|y - ŷ\| / |y|) × 100% | 平均绝对百分比误差 |
| R² | 1 - SS_res / SS_tot | 决定系数 |

## 8. 使用说明

### 8.1 环境配置

```bash
pip install -r requirements.txt
```

### 8.2 快速使用

```python
from src.predictor import LoadPredictor

# 初始化预测器
predictor = LoadPredictor(model_type='xgboost')

# 加载数据并训练
predictor.load_data('data/load_data.xlsx')
predictor.train()

# 预测未来负荷
result = predictor.predict(steps=60)
```

### 8.3 数据格式要求

Excel文件应包含以下列：

| 列名 | 类型 | 说明 |
|------|------|------|
| timestamp | datetime | 时刻，精确到分钟 |
| load | float | 电力负荷值 |
