# 科学计算器产品说明

## 1. 产品概述

### 1.1 产品名称
科学计算器 (Scientific Calculator)

### 1.2 产品类型
Web 端单页应用

### 1.3 产品简介
一款功能强大的网页计算器，支持普通计算和科学计算两种模式。普通模式满足日常基本运算需求，科学模式提供三角函数、对数、幂函数等高级数学功能。采用现代化的用户界面设计，为用户提供流畅、高效的计算体验。

### 1.4 目标用户
- 需要进行日常数学计算的用户
- 学生、教育工作者
- 工程师和科研人员
- 追求简洁界面和快速响应的用户

## 2. 产品功能

### 2.1 模式切换
- **普通模式**：满足基本日常计算需求
- **科学模式**：提供高级数学函数计算
- **一键切换**：通过顶部按钮快速切换模式

### 2.2 普通模式功能
- **基本运算**：加法(+)、减法(-)、乘法(×)、除法(/)
- **取余运算**：支持百分号(%)计算
- **清除功能**：一键清除所有输入(C)
- **删除功能**：逐字删除最后一位数字(DEL)
- **等号计算**：显示计算结果(=)

### 2.3 科学模式功能

#### 三角函数（角度制）
| 函数 | 功能 | 示例 |
|-----|------|------|
| sin | 正弦函数 | sin(30°) = 0.5 |
| cos | 余弦函数 | cos(60°) = 0.5 |
| tan | 正切函数 | tan(45°) = 1 |
| sin⁻¹ | 反正弦函数 | sin⁻¹(0.5) = 30° |
| cos⁻¹ | 反余弦函数 | cos⁻¹(0.5) = 60° |
| tan⁻¹ | 反正切函数 | tan⁻¹(1) = 45° |

#### 对数函数
| 函数 | 功能 | 示例 |
|-----|------|------|
| log | 常用对数（底10） | log(100) = 2 |
| ln | 自然对数（底e） | ln(e) = 1 |

#### 幂函数与根函数
| 函数 | 功能 | 示例 |
|-----|------|------|
| √ | 平方根 | √(16) = 4 |
| x² | 平方 | 5² = 25 |
| x³ | 立方 | 2³ = 8 |
| xʸ | 幂运算 | 2³ = 8 |

#### 常数
| 函数 | 功能 | 值 |
|-----|------|------|
| π | 圆周率 | 3.1415926535... |
| e | 自然常数 | 2.7182818284... |

#### 其他函数
| 函数 | 功能 | 示例 |
|-----|------|------|
| n! | 阶乘 | 5! = 120 |
| |x| | 绝对值 | |-5| = 5 |
| 1/x | 倒数 | 1/(4) = 0.25 |
| ± | 符号取反 | 5 → -5 |

### 2.4 输入功能
- **数字键**：0-9
- **小数点**：支持小数输入
- **运算符**：+、-、×、/、%
- **括号**：() 用于优先级控制

### 2.5 显示功能
- **主显示屏**：显示当前输入或计算结果
- **历史记录**：显示运算表达式历史
- **科学计数法**：数字超过12位时自动转换为科学计数法显示
- **错误提示**：无效操作时显示"Error"

### 2.6 键盘支持
| 按键 | 功能 |
|-----|------|
| 0-9 | 数字输入 |
| . | 小数点 |
| + - * / | 运算符 |
| Enter 或 = | 计算结果 |
| Escape | 清除所有 |
| Backspace | 删除一位 |
| % | 取余 |
| ( ) | 括号 |

## 3. 产品特点

### 3.1 界面设计
- 深色主题背景，配色方案现代优雅
- 圆角按钮设计，提升视觉效果
- 模式切换按钮，清晰明了
- 科学函数使用绿色高亮显示
- 响应式布局，适配不同屏幕尺寸

### 3.2 交互设计
- 按钮悬停效果：hover 时背景变亮并轻微放大
- 按钮点击效果：active 时轻微缩小
- 实时输入反馈：每次按键立即更新显示
- 模式切换动画：平滑过渡

### 3.3 错误处理
- 除数为零时显示"Error"
- 无效输入（如负数平方根）显示"Error"
- 对数函数输入必须为正数
- 阶乘函数输入必须为非负整数

### 3.4 技术特点
- 纯前端实现，无需后端服务器
- 使用原生 JavaScript，无外部依赖
- 文件轻量，加载速度快
- 跨浏览器兼容性好

## 4. 产品规格

### 4.1 技术规格
- **前端技术**：HTML5、CSS3、JavaScript (ES6+)
- **文件结构**：
  - `index.html`：主页面
  - `styles.css`：样式表
  - `script.js`：业务逻辑
- **响应式断点**：适配 380px 及以上屏幕宽度

### 4.2 性能规格
- 页面加载时间：< 1秒
- 计算响应时间：< 50ms
- 最大输入位数：12位
- 支持的数字范围：JavaScript number 类型范围

### 4.3 布局规格
- **普通模式**：4列 × 5行按钮布局
- **科学模式**：4列 × 7行按钮布局（包含4行科学函数）
