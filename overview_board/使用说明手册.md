# 部门研发效能看板系统 - 使用说明手册

## 一、系统概述

### 1.1 系统简介

部门研发效能看板系统是一个整合多数据源的研发管理可视化平台，旨在帮助部门和员工解决数据分散、缺乏全局视野的问题。

### 1.2 解决的核心问题

| 用户类型 | 核心痛点 | 系统解决方案 |
|----------|----------|--------------|
| 部门管理层 | 无法快速了解各产品线研发投入占比和产出效能 | 产品线投入产出对比图表 |
| 部门管理层 | 项目进度分散在多个工具中，缺乏全局视野 | 统一的项目进度中心 |
| 部门管理层 | 人员利用率不清晰 | 人员利用率热力图 |
| 部门管理层 | 非功能性工作难以量化 | 工作类型分布统计 |
| 普通员工 | 不清楚自己在整体目标中的位置 | 目标对齐视图 |
| 普通员工 | 跨团队信息不对称 | 团队工作概览 |
| 普通员工 | 个人贡献难以量化评估 | 个人贡献统计 |

### 1.3 数据来源

系统整合以下数据源：

- **spif系统**：员工每日工作日志（工作类型、时间、工作性质等）
- **MS Project**：项目计划与进度跟踪
- **Excel表格**：部分项目的计划管理与执行跟踪
- **禅道**：软件缺陷管理与闭环跟踪

## 三、功能模块说明

### 3.1 部门总览

**入口**：点击顶部导航栏「部门总览」标签

**核心功能**：

| 功能 | 说明 |
|------|------|
| 数据源状态 | 显示各数据源的连接状态和最后同步时间 |
| KPI卡片 | 在研项目数、本月投入工时、缺陷关闭率、人均效能 |
| 产品线投入占比 | 饼图展示各产品线研发投入占比 |
| 月度工作量趋势 | 折线图展示计划工时与实际工时对比 |
| 投入产出对比 | 柱状图展示各产品线投入工时、功能点产出、缺陷关闭数 |
| 风险预警 | 列出存在延期或高风险的项目 |

**关键指标说明**：

- **在研项目数**：当前处于"进行中"状态的项目总数
- **本月投入工时**：本月所有员工记录的有效工时总和
- **缺陷关闭率**：(已关闭缺陷数 / 发现缺陷总数) × 100%
- **人均效能**：实际产出工时 / 计划工时 × 100%

### 3.2 项目进度

**入口**：点击顶部导航栏「项目进度」标签

**核心功能**：

| 功能 | 说明 |
|------|------|
| 项目统计 | 总项目数、进行中、已延期、已完成数量 |
| 项目列表 | 展示所有项目的基本信息、计划/实际工时、进度条 |
| 进度可视化 | 进度条颜色表示进度状态（绿色>80%, 黄色60-80%, 红色<60%）|
| 状态标识 | 延期/进行中/已完成状态标签 |

**操作说明**：

- 查看项目列表，了解各部门项目分布
- 通过进度条颜色快速识别滞后项目
- 点击具体项目可查看项目详情（原型阶段暂未实现）

### 3.3 人员效能

**入口**：点击顶部导航栏「人员效能」标签

**核心功能**：

| 功能 |说明 |
|------|------|
| 人员统计 | 部门总人数、平均利用率、过载人数、闲置人数 |
| 团队分布 | 柱状图展示各产品线团队人员配置 |
| 利用率热力图 | 以周为单位，展示每位成员每天的工作饱和度 |
| 成员列表 | 展示成员基本信息、当前项目、工时、利用率 |

**热力图颜色说明**：

| 颜色 | 利用率范围 | 状态说明 |
|------|------------|----------|
| 浅绿 | <70% | 闲置，可分配更多任务 |
| 深绿 | 70-80% | 正常，有一定余量 |
| 绿色 | 80-100% | 良好，充分利用 |
| 橙色 | 100-110% | 满负荷，需关注 |
| 红色 | >110% | 过载，需调整工作量 |

### 3.4 个人工作台

**入口**：点击顶部导航栏「个人工作台」标签

**核心功能**：

| 功能 | 说明 |
|------|------|
| 个人KPI | 本月工时、参与项目数、完成缺陷数、目标达成率 |
| 目标对齐 | 展示个人目标与部门/项目目标的关联及完成进度 |
| 工作类型分布 | 饼图展示个人各类工作（开发、评审、会议等）占比 |
| 任务清单 | 列出本周待办任务及截止时间 |
| 贡献统计 | 按项目展示个人工作产出和质量评分 |

**目标对齐视图说明**：

- 显示个人目标与上级目标的对应关系
- 进度条直观展示目标完成情况
- 帮助员工理解个人工作对整体的贡献价值

## 四、数据更新说明

### 4.1 数据同步

系统数据同步策略：

| 数据源 | 同步频率 | 同步方式 |
|--------|----------|----------|
| spif系统 | 每日 | API接口/数据库直连 |
| MS Project | 每周 | 文件导入(MPP/XML) |
| Excel表格 | 每周 | 文件导入(XLSX) |
| 禅道 | 每日 | API接口/数据库直连 |

### 4.2 数据展示

- 系统展示的是最新同步的数据
- 首页显示"最后同步"时间
- 如需手动刷新，请联系系统管理员

## 五、常见问题

### Q1: 为什么看不到我的工作记录？

请确认：
1. 您的spif账号是否已录入系统
2. 当日工作日志是否已填写并提交

### Q2: 项目进度数据与实际情况不符？

数据来源于Project或Excel导入，如有差异请检查源文件数据是否更新。

### Q3: 如何申请账号或权限？

请联系系统管理员进行账号配置。
