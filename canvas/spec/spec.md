# 画板应用规范文档

## 项目概述
创建一个基于 HTML5 Canvas 的网页画板应用，采用二次元浅蓝色调风格，用户可以在页面上自由绘画、绘制基本形状、使用油漆桶填充，并支持保存作品到本地存储。

## 功能需求

### 1. 核心功能
- **绘画功能**: 使用鼠标在画布上自由绘制
- **颜色选择**: 支持选择画笔颜色
- **画笔大小**: 可调节画笔粗细
- **画笔硬度**: 可调节画笔边缘羽化程度（0-100）
- **清除画布**: 一键清空画布
- **油漆桶工具**: 填充指定区域颜色
- **基本形状**: 支持矩形、椭圆形等形状绘制
- **线条和填充设置**: 可分别设置线条颜色和填充颜色
- **存储功能**: 将绘画作品保存到本地

### 2. 存储功能
- **本地存储**: 使用 LocalStorage 保存绘画数据
- **下载功能**: 支持将画布导出为 PNG 或 JPG 图片下载
- **格式选择**: 用户可选择保存为 PNG 或 JPG 格式
- **历史记录**: 保存最近的绘画作品（可选）

### 3. 用户界面
- **设计风格**: 二次元风格，浅蓝色色调为主
- **界面设计**: 简洁直观的界面设计
- **布局方式**: 左侧工具栏 + 右侧画布的布局
- **画布区域**: 画布占据主要区域
- **工具栏**: 左侧垂直工具栏，包含工具分类区块
  - 颜色设置：线条颜色、填充颜色
  - 画笔设置：大小、硬度滑块
  - 工具选择：画笔、橡皮擦、油漆桶
  - 形状选择：自由、矩形、椭圆
  - 填充模式：无、线条、填充、两者
  - 操作按钮：撤销、重做、清除
  - 保存下载：保存、下载
- **响应式布局**: 适配不同屏幕尺寸
  - 桌面端（>768px）：左侧固定工具栏（260px）
  - 平板端（≤768px）：工具栏移至顶部，两列布局
  - 手机端（≤480px）：工具栏单列布局，紧凑设计
  - 小屏手机（≤360px）：按钮纵向排列

## 技术栈
- **前端**: HTML5 + CSS3 + JavaScript (原生)
- **画布**: HTML5 Canvas API
- **存储**: LocalStorage + Canvas toDataURL + 服务器存储（可选）
- **样式**: 二次元风格，浅蓝色调，响应式设计

## 功能详细说明

### 画布设置
- 画布尺寸：自适应窗口大小，最小 800x600
- 背景色：白色
- 边框：浅灰色边框

### 画笔工具
- 颜色选择器：默认黑色，支持任意颜色
- 画笔大小：范围 1-50px，默认 5px
- 画笔硬度：范围 0-100，默认 100（100 为边缘清晰，0 为最大羽化）
- 绘画模式：连续绘制，支持平滑线条

### 油漆桶工具
- 填充模式：点击填充封闭区域
- 填充颜色：使用当前选择的填充颜色
- 容差设置：可调节填充容差（可选）

### 基本形状工具
- 矩形：支持绘制矩形（实心/空心）
- 椭圆形：支持绘制椭圆形（实心/空心）
- 线条和填充：可分别设置线条颜色和填充颜色
- 绘制模式：拖动绘制，实时预览

### 保存功能
- 本地存储：将 Canvas 内容转为 Base64 存储到 LocalStorage（PNG 格式）
- 下载图片：将画布内容导出为 PNG 或 JPG 格式文件
- JPG 质量：可调节 JPG 压缩质量，默认 0.92
- 服务器保存：支持从服务器保存到本地（可选）

### 撤销/重做功能
- 历史记录：最多保存 50 步操作历史
- 撤销功能：Ctrl+Z 或点击撤销按钮
- 重做功能：Ctrl+Y 或点击重做按钮
- 状态管理：自动管理历史栈，支持跨操作撤销

### 用户体验
- 流畅的绘画体验，低延迟
- 清晰的视觉反馈
- 操作提示和状态显示
- 二次元风格界面，浅蓝色调，视觉舒适
- 响应式布局，多设备友好
