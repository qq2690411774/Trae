# 字节输入输出模拟器 - 实施计划

## 项目概述
创建一个交互式网页应用，模拟8位字节的输入输出系统：
- 8个开关控制字节的每一位
- 8个红色LED显示当前字节状态
- 实时显示字节的十进制和十六进制值

## 功能规格

### 1. 开关输入区
- 8个垂直拨动开关，代表字节的8位 (Bit 0 - Bit 7)
- 开关打开(ON) = 1, 关闭(OFF) = 0
- MSB在左边，LSB在右边（符合人类阅读习惯）

### 2. LED输出区
- 8个红色圆形LED，与开关一一对应
- 开关闭合时LED点亮（表示该位为1）
- LED直径约30px，红色发光效果

### 3. 数值显示
- 十进制显示 (0-255)
- 十六进制显示 (00-FF)
- 二进制显示 (00000000-11111111)

### 4. 实时交互
- 点击开关立即改变状态
- LED和数值实时更新
- 无需提交按钮

## 界面布局
```
+----------------------------------+
|       字节输入输出模拟器          |
+----------------------------------+
|  [LED] [LED] [LED] [LED]        |
|  [LED] [LED] [LED] [LED]        |
|   ↓       ↓      ↓      ↓       |
|  [SW]   [SW]   [SW]   [SW]       |
|  [SW]   [SW]   [SW]   [SW]       |
+----------------------------------+
|  十进制: 128  | 十六进制: 80      |
|  二进制: 10000000                |
+----------------------------------+
```

## 技术实现
- 纯HTML/CSS/JavaScript
- 单文件实现
- 无需任何外部依赖

## 验收标准
1. 8个开关可以独立控制
2. 8个LED正确响应开关状态
3. 数值显示正确（十进制、十六进制、二进制）
4. 实时更新，无延迟
