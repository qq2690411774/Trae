# 字节累加模拟器 - 实施计划

## 项目概述
创建一个交互式网页应用，可视化演示8位字节的累加过程：
- 数字从0开始，每0.3秒自动加1
- 达到255后溢出回0（循环计数）
- 8个LED指示灯实时显示当前字节的二进制状态
- 8个开关与LED联动，可手动控制或显示状态

## 功能规格

### 1. 自动累加功能
- 初始值：0
- 递增间隔：300毫秒（0.3秒）
- 循环逻辑：达到255后加1变为0（模256运算）
- 页面加载后自动开始累加

### 2. LED 指示灯
- 8个红色圆形LED，代表字节的8位 (Bit 0 - Bit 7)
- MSB在左边，LSB在右边
- LED点亮表示该位为1，熄灭表示该位为0
- 带有发光效果，视觉美观

### 3. 开关组件
- 8个垂直拨动开关，与LED一一对应
- 开关状态与LED同步（联动显示）
- 显示 "Bit 0" 到 "Bit 7" 标签

### 4. 数值显示
- 十进制显示 (0-255)
- 十六进制显示 (00-FF)
- 二进制显示 (00000000-11111111)

### 5. 控制按钮
- "开始计数" 按钮：启动自动累加
- "停止计数" 按钮：暂停自动累加
- 按钮根据状态自动切换显示

### 6. 联动机制
- byteValue 是唯一数据源
- updateDisplay() 函数统一更新所有显示元素
- 手动操作和自动累加共享同一显示逻辑

## 技术实现
- 纯HTML/CSS/JavaScript
- 单文件实现
- 无需任何外部依赖

## 验收标准
1. 页面加载后自动从0开始累加
2. 每0.3秒自动加1
3. 达到255后自动回到0
4. 8个LED正确显示当前字节的二进制状态
5. 8个开关与LED状态同步
6. 数值显示正确（十进制、十六进制、二进制）
7. 开始/停止按钮可以控制累加
8. 所有显示元素保持完全联动
