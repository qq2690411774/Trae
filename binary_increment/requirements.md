# 字节累加模拟器 - 需求规格文档

## 1. 项目概述

### 项目名称
字节累加模拟器

### 项目类型
单页面 Web 应用（纯 HTML/CSS/JavaScript）

### 核心功能概述
一个可视化演示工具，用于展示8位字节的累加过程。数字从0开始，每0.3秒自动加1，达到255后溢出回0，形成循环计数。

### 目标用户
- 计算机科学学习者
- 电子/数字电路爱好者
- 需要二进制计数演示工具的用户

## 2. 功能需求

### 2.1 自动累加功能

#### 2.1.1 计数规则
| 属性 | 值 |
|------|-----|
| 初始值 | 0 |
| 递增间隔 | 300毫秒（0.3秒） |
| 最大值 | 255 |
| 溢出行为 | 加1后回到0（模256运算） |

#### 2.1.2 启动方式
- 页面加载后自动开始累加

### 2.2 控制按钮

#### 2.2.1 开始计数按钮
- 文字：开始计数
- 样式：绿色渐变背景
- 可见条件：当前未在累加时显示

#### 2.2.2 停止计数按钮
- 文字：停止计数
- 样式：红色渐变背景
- 可见条件：当前正在累加时显示

### 2.3 LED 指示灯

#### 2.3.1 规格
- **数量**：8个
- **形状**：圆形
- **尺寸**：桌面端 40x40px，移动端 30x30px
- **颜色**：红色
- **排列**：Bit 7 在最左边，Bit 0 在最右边（MSB → LSB）

#### 2.3.2 状态
| 状态 | 视觉效果 |
|------|----------|
| 关闭（0） | 深红色背景，无发光 |
| 打开（1） | 径向渐变红色，带发光效果 |

#### 2.3.3 联动
- 与 byteValue 变量同步
- 根据对应 bit 位的值自动更新

### 2.4 开关组件

#### 2.4.1 规格
- **数量**：8个
- **类型**：垂直拨动开关
- **尺寸**：桌面端 30x60px，移动端 24x50px
- **位置**：每个开关位于对应LED下方

#### 2.4.2 标签
- 显示 "Bit 0" 到 "Bit 7"
- "ON" 标签在开关闭合时高亮
- "OFF" 标签在开关断开时高亮

#### 2.4.3 状态
| 状态 | 视觉效果 |
|------|----------|
| OFF（0） | 拨片在顶部，灰色 |
| ON（1） | 拨片在底部，绿色高亮 |

#### 2.4.4 联动
- 与 LED 状态同步
- 点击可切换状态（与累加联动）

### 2.5 数值显示

#### 2.5.1 显示格式
| 类型 | 格式 | 范围 |
|------|------|------|
| 十进制 | 普通数字 | 0-255 |
| 十六进制 | 两位大写，填充0 | 00-FF |
| 二进制 | 8位字符串，填充0 | 00000000-11111111 |

### 2.6 联动机制

#### 2.6.1 数据流
```
byteValue (唯一数据源)
    ↓
updateDisplay() (统一更新)
    ├── LED 灯状态
    ├── 开关状态
    ├── 十进制数值
    ├── 十六进制数值
    └── 二进制数值
```

#### 2.6.2 触发路径
- 自动累加：setInterval → autoIncrement() → updateDisplay()
- 手动操作：点击开关 → toggleBit() → updateDisplay()

## 4. 技术实现

### 4.1 文件结构
```
binary_increment/
├── index.html       # 单文件应用（HTML + CSS + JavaScript）
├── plan.md          # 实施计划文档
└── requirements.md  # 需求规格文档
```

### 4.2 核心变量
```javascript
let byteValue = 0;                    // 当前字节值 (0-255)
let autoIncrementInterval = null;     // 自动累加定时器
```

### 4.3 核心函数
| 函数名 | 功能 | 调用场景 |
|--------|------|----------|
| init() | 初始化页面，创建组件 | 页面加载 |
| toggleBit(bit) | 切换指定位 | 点击开关 |
| autoIncrement() | 累加字节值 | 定时器触发 |
| startAutoIncrement() | 启动自动累加 | 点击开始按钮、页面加载 |
| stopAutoIncrement() | 停止自动累加 | 点击停止按钮 |
| updateDisplay() | 更新所有显示 | 任何值变化时 |
